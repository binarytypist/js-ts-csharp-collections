# Symbols / Iterators / Generators

This lesson introduces three related JavaScript features that help you write more expressive and flexible code.

## What each one does

- Symbol: creates a unique identifier that will not clash with other properties.
- Iterator: allows an object to be traversed step by step.
- Generator: lets you pause and resume function execution with `yield`.

## Files

- [symbols-iterators-generators.ts](symbols-iterators-generators.ts) - TypeScript example
- [symbols-iterators-generators.js](symbols-iterators-generators.js) - JavaScript example

## Quick examples

- Use `Symbol()` for hidden or special property names.
- Use an iterator when you want manual control over looping.
- Use a generator when you want a function to produce a sequence of values lazily.
