Implement these in `starter.js`:

1. `filterActiveEmployees(employees)`
2. `sortBySalaryDesc(employees)`
3. `findEmployeeById(employees, id)`
4. `compareObjectArraysById(arr1, arr2)`
5. `findMissingIds(expectedIds, returnedIds)`
6. `groupByDepartment(employees)`
7. `countByRole(employees)`
8. `transformApiUsers(apiResponse)`
9. `uniqueSkills(employees)`
10. `intersectionById(arr1, arr2)`
11. `differenceById(arr1, arr2)`
12. `mergeByIdPreferRight(left, right)`
13. `topNBySalary(employees, n)`
14. `dedupeByIdStable(items)`
15. `partitionByActive(employees)`

Run tests:

```bash
node object-challenge-pack/tests.js
```
