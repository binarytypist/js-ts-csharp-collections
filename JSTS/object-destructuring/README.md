# Object Destructuring Practice

This folder contains JavaScript and TypeScript examples for:

- extracting values from objects
- extracting values from nested objects
- combining object and array destructuring
- extracting values inside loops
- extracting values from function arguments
- copying object properties into a new object
- copying properties from multiple objects

Run the JavaScript file with:

```bash
node object-destructuring.js
```

Compile and check the TypeScript file with:

```bash
tsc object-destructuring.ts
```
