# Practical JavaScript

This folder contains JavaScript and TypeScript solutions for a progressive interview-style practice set.

## What is included
- Basic array and object exercises
- Array processing with map, filter, reduce, find
- Functions, closures, and pagination
- Async JavaScript, debounce, retry, and caching
- A full employee management system practice set

## Run the JavaScript version

```bash
node practical-javascript.js
```

## Try the practice version first

```bash
node practical-javascript-practice.js
```

## Run the TypeScript version

```bash
npx tsc practical-javascript.ts
```
